Project Overview

Interactive web application designed to simulate the BB84 Quantum Key Distribution (QKD) protocol. Developed entirely as a client-side tool without server dependencies(and its fast), utilising Vanilla JavaScript, HTML5, CSS3, KaTeX, and the Canvas API.

Key Features

  • Simulation of photon transmission over a quantum channel with adjustable noise parameters and Quantum Bit Error Rate (QBER) auditing.
  • Advanced cryptographic post-processing pipelines featuring Information Reconciliation via Cascade and LDPC (Low-Density Parity-Check) Tanner graph belief propagation.
  • Privacy amplification using Universal Toeplitz Hashing to mitigate eavesdropping and generate unconditionally secure keys ready for the ChaCha20-Poly1305 cipher suite
